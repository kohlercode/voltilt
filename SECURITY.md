# Security policy

Voltilt is an open-source UI library. Reports of vulnerabilities in the published packages are welcome via GitHub issues (or a private channel if one is listed on [kohlercode.com](https://kohlercode.com)).

## Do not commit secrets

This repo is public. Never add credentials, API keys, passphrases, private keys, `.env` files, or absolute personal filesystem paths. See [AGENTS.md](./AGENTS.md).
